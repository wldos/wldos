📋 统一响应格式说明

WLDOS 框架统一响应格式：
{ "code": 200, // 业务状态码：200=成功，非200=失败 "message": "", // 响应消息：成功时为空字符串，失败时为错误信息 "data": { ... }, // 响应数据：业务数据 "success": true // 操作是否成功：true=成功，false=失败 }
前端处理方式：
  • 使用 res.code === 200 或 res.success === true 判断业务是否成功
  • 使用 res.data 获取业务数据
  • 使用 res.message 获取错误信息（失败时）
